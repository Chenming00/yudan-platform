# ADR-004：Cloudflare R2 保存图片和附件

- 状态：已接受
- 日期：2026-09-01

## 决策

图片和附件不写入数据库或 Vercel 文件系统，统一存放在 Cloudflare R2。数据库只保存资源元数据、对象键、所属家庭、可见性、状态和业务关联。

浏览器通过短时 Presigned URL 直传 R2。应用服务负责登录、权限、文件限制和上传确认；上传完成后通过 HEAD 校验对象大小与类型，再将资源从 `PENDING` 变为 `READY`。

## 安全边界

- 健康资料、衣柜图片等默认使用私有 Bucket；
- 数据库不保存 Presigned URL；
- 对象键由服务端生成，不包含邮箱等个人信息；
- 下载私有资源前重新检查家庭范围与权限；
- 删除先做逻辑删除，后台任务再执行可重试的物理清理；
- 存储通过 `MediaStorage` 接口封装，业务模块不依赖 R2 SDK。
