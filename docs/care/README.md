# 儿童保健模块

儿童保健负责宝宝资料、生长测量、疫苗接种和儿保、就诊、用药、保健品记录。

## 业务规则

- 健康数据按 `householdId` 隔离，并要求 `care.read` 或 `care.write` 权限。
- 免费项目只写入健康模块，不自动生成账本支出。
- 自费项目先由统一账本创建 `CHILD_CARE` Allocation，再把 Allocation ID 写入保健记录；模块不会复制金额。
- 身高、体重、头围最多三位小数；体重必须大于 0 且不超过 100 kg。
- 同一宝宝、同一疫苗、同一天不能重复登记。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET/POST | `/api/care/babies` | 宝宝资料 |
| GET/POST | `/api/care/growth` | 生长测量 |
| GET/POST | `/api/care/vaccines` | 疫苗接种 |
| GET/POST | `/api/care/records` | 儿保、就诊、用药、保健品和其他记录 |

写接口使用统一响应格式，并由服务端重新校验权限和家庭归属。医疗附件应通过资源模块上传确认，再保存 `MediaAsset` 关联。

A09 组合记账负责把一次付款同时写入账本与儿童保健记录，并在同一数据库事务内完成；A10 负责旧健康数据导入和校验。
